# 전원 관리

제어센터의 전원 모드 옆 화살표에서 엽니다. 직접 실행은 `lucy-shell power`입니다.

- 상단: 절전 / 균형 / 성능 모드를 직접 선택합니다.
- 현재 배터리 잔량: 큰 숫자와 얇은 게이지로 표시합니다.
- 배터리 성능 상태: 최대 충전 용량 / 설계 용량 비율을 별도의 타원형 게이지로 표시합니다. 데이터가 없으면 ‘정보 없음’으로 표시합니다.
- 잔량 칸에는 ‘전원 연결’ 또는 ‘배터리 사용’만 표시하고 충전 대기 등의 상태·예상 시간은 표시하지 않습니다. 충전 제한은 별도의 충전 상한 항목에서 확인합니다. 전력 라벨은 ‘소비 전력’으로 통일합니다. 배터리 사용 중에는 방전 전력, 전원 연결 중에는 지원되는 AMD 센서 값을 사용합니다. 후자는 화면·외장 GPU 등을 포함한 시스템 전체 소비 전력과 다릅니다. 측정값이 없으면 ‘측정 불가’로 표시합니다.
- 충전 상한: ASUS 서비스가 지원하는 장치에서 80% / 100%를 선택합니다. 시작할 때 기존 상한을 바꾸지 않습니다.
- 절전 방지: 자동 화면 꺼짐과 자동 절전을 일시 중지합니다. 수동 잠금·절전은 막지 않으며, Lucy 재시작 시 해제됩니다.
- 자동 절전 설정: 배터리 사용 / 전원 연결 조건별 **다음 자동 전환에 사용할 모드**와 화면 꺼짐·절전 시간을 설정합니다. 이곳의 모드 선택은 현재 모드를 바꾸지 않습니다. 시간 버튼 바로 아래에서 목록을 선택하며, 목록 밖 클릭 또는 Escape로 닫습니다. 배터리 조건에는 20% 미만 절전 전환도 있습니다.

화면 맨 위 탭에서만 휠로 이전·다음 항목을 선택합니다. 본문의 자동 전환 모드·전원 조건 선택 영역에서는 페이지가 스크롤됩니다. 자동 절전 그룹은 320ms 동안 높이와 화살표를 보간하며 펼치고 접습니다. 접히는 중에는 숨겨지는 항목을 누를 수 없습니다.

## 저장과 기존 서비스

Lucy가 관리하는 설정은 `~/.config/lucy/power.json`에 원자적으로 저장됩니다. 설정 변경 전에는 파일을 만들지 않습니다. 유효하지 않은 파일은 덮어쓰지 않고 오류를 표시합니다.

ASUS의 기존 자동 전환 설정은 처음에는 그대로 읽습니다. ASUS의 예약 프로필 저장 API는 현재 모드까지 즉시 바꾸므로 사용하지 않습니다. Lucy에서 특정 전원 조건의 자동 전환 설정을 처음 편집하면, 그 조건의 ASUS 자동 전환만 끄고 Lucy가 저장·전환을 맡습니다. 다른 조건과 현재 모드는 유지하며, 저장 실패 시 이전 ASUS 자동 전환 상태를 복구합니다. 충전 상한은 기존 `asusd` API를 사용합니다. ASUS 실행 파일은 수정하지 않습니다. 다른 장치에서는 지원되는 기능만 활성화됩니다.

새 화면 꺼짐·자동 절전 타이머와 20% 미만 자동 절전 모드는 기본적으로 꺼져 있습니다. 기존 ASUS 자동 전환 설정은 유지합니다. 저전력 자동 전환은 진입 시 한 번 적용하며, 이후 수동으로 고른 모드를 계속 덮어쓰지 않습니다.

유휴 타이머는 상주 Lucy 바에서 Wayland `ext-idle-notify-v1`을 사용하며, 다른 앱의 Wayland 유휴 방지를 존중합니다. 절전 직전 잠금은 `integration/lucy-idle.service`의 `swayidle before-sleep` 처리와 별도 Lucy 잠금 프로세스가 담당합니다. 준비 실패 시 사용하는 Swaylock과 기존 PAM 설정은 유지합니다. 자세한 잠금 동작은 [OSD와 잠금화면](osd-lock.md)을 참고하세요.

## 검증

`cargo test --release --offline --locked`로 배터리 계산, 설정 검증·저장, 가상 D-Bus 제어를 검사합니다. 실제 장치의 프로필이나 충전 상한은 변경하지 않습니다.

Niri 화면 테스트는 `cargo test --release --offline --locked --test power_ui -- --ignored --nocapture`입니다. 읽기 전용 미리 보기에서 실행하며 자동 절전은 요청하지 않습니다.
