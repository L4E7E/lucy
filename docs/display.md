# 디스플레이

제어센터의 밝기 게이지 옆 설정 버튼 또는 `lucy-shell display`로 엽니다.

- **식별**: 각 활성 화면 중앙에 번호와 연결 이름을 2.5초 표시합니다. 키보드 포커스나 마우스 입력을 가로채지 않습니다.
- **배치**: 미리보기의 화면을 드래그한 뒤 ‘배치 적용’을 누릅니다. 실제 논리 크기와 배율을 반영하고 모서리에 맞춰 붙입니다. 겹치는 배치는 적용할 수 없습니다.
- **해상도·주사율**: 해당 화면이 보고한 모드만 선택합니다. `59.940 Hz` 같은 실제 주사율을 보존합니다.
- **배율**: 화면별로 선택합니다. 다른 화면의 배율을 일괄 변경하지 않습니다.
- **밝기**: 내장 화면은 해당 GPU의 백라이트, 외장 화면은 DDC/CI를 사용합니다. 외장은 `ddcutil`, 모니터의 DDC/CI 활성화, I²C 접근 권한이 필요합니다. 지원되지 않으면 이유를 표시하고 조절을 비활성화합니다.

해상도·주사율·배율·배치는 먼저 임시 적용됩니다. **15초 안에 ‘유지’를 누르지 않으면 되돌립니다.** 확인 대기 중에도 다시 선택할 수 있으며, 마지막 변경부터 15초를 다시 셉니다. 여러 번 변경했어도 ‘되돌리기’와 시간 만료 시 처음 변경 전 상태로 복원합니다. Lucy의 정상 종료 시에도 미확정 변경을 복원합니다. 강제 종료나 컴포지터 장애까지 보장하는 별도의 복구 서비스는 아닙니다.

확정한 설정과 야간 모드 설정은 `~/.config/lucy/display.json`에 원자적으로 저장합니다. Lucy 재시작·화면 재연결 시 해당 모니터에만 적용하며 Niri의 기존 KDL 파일은 수정하지 않습니다. 디스플레이를 구분할 때 연결 이름·제조사·모델·일련번호를 함께 사용합니다.

## 야간 모드

‘야간 모드’ 탭에서 켜기/끄기, 자동 적용 시간, 2500–6500 K 색온도를 설정합니다. 낮은 값일수록 따뜻합니다. 시작·종료의 **시·분 숫자 위에서 각각 휠을 움직이면** 해당 값만 1단위로 변경합니다. 위로 돌리면 증가하고 아래로 돌리면 감소하며, 분이 59에서 00으로 돌아가도 시는 그대로 유지합니다. 자정을 넘는 일정도 지원합니다.

Wayland `zwlr_gamma_control_v1`로 직접 제어하므로 `wlsunset` 같은 외부 프로세스를 추가하지 않습니다. 끄거나 Lucy를 종료하면 감마 제어를 해제합니다. 다른 색온도 프로그램을 동시에 실행하지 마세요. 프로토콜·드라이버가 지원하지 않으면 오류를 표시합니다.

## 검증

```sh
cargo test --release --locked --offline
cargo clippy --release --locked --offline -- -D warnings
# 실제 입력, 읽기 전용 미리보기: 시스템 설정 변경 없음
cargo test --release --locked --offline --test display_ui -- --ignored --nocapture
# 실제 화면에 따뜻한 색온도를 잠깐 적용 후 해제
cargo test --release --locked --offline --bin lucy-shell gamma::tests::compositor_accepts_native_gamma_and_releases_it_on_disable -- --ignored --nocapture
```

듀얼 화면 실물 배치와 외장 DDC 밝기는 해당 하드웨어를 연결해 별도로 검증해야 합니다.
