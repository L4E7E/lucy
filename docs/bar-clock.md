# 시계와 시스템 상태 표시

상태바와 확장 패널은 같은 GPU 재질·외곽선 계산을 사용한다. 닫힌 상태의
배경·얇은 반사 테두리가 제어센터·시스템 모니터·알림센터가 열리는 동안 그대로
늘어나며, 높이 100px에서 별도 패널 재질로 바꾸지 않는다. 글자·아이콘만
캐시하고 재질은 현재 표면 크기로 합성한다. SHM 대체 경로도 같은 상태바
재질 함수를 공유한다. 기존 기본 알파·블러·곡률 상한·애니메이션 시간은 유지한다.
GPU 회귀 검사는 34/35/60/99/100/101/250/500px에서 상태바·확장 경로의
전체 RGBA 픽셀 일치를 검사한다. 실제 표면 확장 검사는 별도로 실행한다.

달력 위 시계는 시스템 글꼴의 Medium 굵기, 58px 크기를 사용한다. 숫자는
동일 폭(`tnum`)이고 콜론만 약하게 표시한다. 시계 바로 아래에는
`11월 10일 화요일` 형식의 오늘 날짜를 시스템 글꼴 18px로 가운데 정렬한다.
시계·날짜·달력 전체를 기존 배치에서 8px 아래에 둔다. 달력은 기준 배치보다
78px 아래에 두어 날짜 영역과 달력 사이의 28px 간격을 유지한다.
초·날씨·별도 배경판은 추가하지 않으며, 축소 상태바의 날짜 형식과
시스템 글꼴 설정은 유지한다. 오늘 날짜는 달력에서 다른 달을 탐색해도
바뀌지 않으며, 기존 분 단위 갱신으로 자정에 함께 갱신된다.

알림 센터를 열고 닫을 때 시계와 오늘 날짜는 하나의 캐시 텍스처와 논리
캔버스로 움직인다. 시작 너비는 실제 접힌 날짜 바의 너비이며, 표면 확장과
같은 진행률로 최종 가로 중심 160px, 높이 114px에 도달한다. 위젯은 양축
동일한 1/3 배율로 저장하고 `bar_header_height`가 논리 높이 `114 / 3`을
정한다. 호스트는 출력 배율을 적용한 114px 높이 텍스처를 할당하고 hit
좌표에도 같은 높이를 적용한다. 물리 버퍼 배율과 논리 배치를 섞지 않는다.
날짜를 알림 본문에서 다시 그리지 않으며, 본문의 기존
전개·축소·달 넘김·스크롤 애니메이션 곡선과 시간은 유지한다.
축소 시 오늘 날짜 캡션이 사라진 뒤 원래 날짜 바를 같은 캔버스에 합성한다.
두 시계 레이아웃은 한 번의 premultiplied 혼합으로 교체해 겹침 픽셀의
이중 합성을 막는다. 도중에 다시 열거나 닫으면 마지막 표시 프레임에서 이어진다.

이미 열린 달력에서 분이 바뀔 때만 260ms의 짧은 세로 전환을 실행한다.
처음 열기·달 넘기기·다른 상태 갱신에는 이 전환을 실행하지 않는다.
오늘 날짜 캡션에는 분 전환의 세로 이동을 적용하지 않는다.
현재/이전 시계 텍스처만 보관하고 Wayland 프레임 콜백으로 GPU에서 합성한다.
전환이 끝나면 추가 프레임 요청을 멈춘다. SHM 대체 경로는 정적으로 표시한다.

오른쪽 상태바는 온도 → CPU → RAM → 디스크 순서를 유지한다. 아이콘은
옅은 흰색, 값은 선명한 흰색, 단위는 약간 작게 표시한다. 미니 게이지는
사용하지 않고 한 줄로 중앙 정렬한다. 값은 아이콘 바로 옆에, 단위는 값
바로 옆에 붙인다. 각 항목의 마지막 글자와 다음 아이콘 사이의 실제 외곽
간격을 동일하게 맞춘다. `1%`에 `100%`의 빈 자릿수를 붙이지 않는다.
아이콘 중심의 등간격은 사용하지 않는다. 전체 정보 영역의 너비와
제어센터 버튼 위치는 유지한다. 수치는 실제 백엔드 측정값이며, 고온 경고는
색으로 구분한다. 정보 영역 클릭은 [시스템 모니터](system-monitor.md)를 연다.
닫힌 상태바에 별도 폴링이나 상시 애니메이션은 추가하지 않는다.
소리·네트워크·블루투스·배터리 본체 중심도 32px 간격으로 맞춘다.

왼쪽 런처 버튼은 흰색 3×3 앱 그리드 벡터 아이콘이다. 기존 클릭 영역과
작업공간 인디케이터 위치는 그대로 유지하며, 별도 배경을 추가하지 않는다.

```sh
cargo test --release --locked --offline
cargo clippy --release --locked --offline -- -D warnings
cargo test --release --locked --offline --test expansion -- --ignored --nocapture
cargo test --release --locked --offline --test responsiveness -- --ignored --nocapture
```

실제 화면 검증에서는 달력을 열고 분 전환 직전/중간/직후의 상태를
비교한다. 전환 뒤 `animating=false`인지, 프레임마다 `rasterized`가 증가하지
않는지 확인한다. 다중 모니터는 연결된 실제 출력에서 별도로 점검한다.
시계 단위 테스트는 전개·축소 반전의 좌표 연속성, 날짜 중복 방지,
1/1.25/1.5/2배 Cairo 래스터의 최종 시계·날짜 위치와 글꼴 유지를 확인한다.
이 검사는 실제 다중 출력 사이를 이동하는 Wayland 검증을 대신하지 않는다.
